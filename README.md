🐒 LittleMonkeyAdventure
A 2D platformer game developed with Unity and C#.

🛠️ Tech Stack
Engine: Unity

Language: C#

Version Control: Git & GitHub

🚀 Features
Smooth player movement and controls.

Banana collection & score tracking system.

Lives management (Hearts) & Game Over system.

Audio management (SoundManager).

Scene transitions and levels flow.

💻 How to Run
Clone the repository:

Bash
git clone https://github.com/nawalAlrfoo/LittleMonkeyAdventure.git
Open the project in Unity Hub (Unity 6 or compatible version).

Load the game scene and hit Play!
